# Logistics & Financial Performance Optimization
Synthetic advanced Data Analyst portfolio dataset.

Industry: Banking & Finance
Domain / Business Function: Logistics & Supply Chain
Specific area: Transportation cost, shipment efficiency & financial performance

Core business problem:
Which routes, carriers and shipments are driving excessive costs, and how can logistics spending be reduced while maintaining delivery performance?

Designed for MySQL + Power BI. Optional Python can be used for anomaly/outlier analysis, but the core project can be completed without Python.

Main files:
shipments.csv, orders.csv, customers.csv, carriers.csv, routes.csv, warehouses.csv, monthly_budgets.csv, fuel_price_index.csv, data_dictionary.csv

Dataset is fully synthetic.
